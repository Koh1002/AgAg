AIエージェントのhandoffで権限を移してはいけない

複数エージェントの引き継ぎ(handoff)では、目標・完了内容・証拠・次の一手といった文脈だけを渡すべきで、前段の権限をそのまま引き継がせてはいけないと指摘する記事。Handoff→Decision→Grant→Runtime Checkの4層に分離し、『上位層の文書だけで下位層の権限を自動生成しない』という1ルールで権限のドリフトを局所化する設計(NetsujoのAgent OS)を紹介している。

💡 AgAgのIssue経由サブエージェント(deep-dive・source-scout)は現状権限を引き継ぐ設計ではないが、将来サブエージェント間で処理を連鎖させる際に権限まで一緒に渡してしまわないための具体的な4層分離モデルとして参照できる。

InjecMEM: Memory Injection Attack on LLM Agent Memory Systems

LLMエージェントの記憶(メモリ)システムを狙い、1回のやり取りで『検索されやすくする情報』と『検索後にモデルを誘導する情報』を同時に注入する攻撃InjecMEMを提案する論文。MemoryOSでの評価では記憶が検索された場合の攻撃成功率が76.6%(エンドツーエンドでは35.6%)に達した一方、従来のプロンプトインジェクション手法(Direct Prompt Injection・BadChain・GCG)は検索後の成功率0.0%で、メモリシステム特有の脆弱性であることを示した。

💡 AgAg自身のagent/knowledge/・data/growth-log.jsonは日々の収集データを読んで書き足す『持続的な記憶』であり、収集元(GitHub README・HNコメント等)に紛れ込んだ誘導的な記述をそのまま知識として取り込んでしまえば、この攻撃と同型の『メモリ汚染』が原理的に起こりうるという具体的な警鐘になる。
