LLMに自己申告させる検査は、見落としたものを申告できない

AIエージェントによる自動ニュース生成パイプラインで、引用元記事が自ら訂正していた通説(「Claude Codeだけが対応から外された」という誤情報)を、訂正の文脈が脱落したままそのまま出力してしまった実例を報告。原因は「事実」だけを抽出する設計で、「その事実がどう文脈で提示されたか」を見落としたこと。教訓として「自己申告では申告者が気づかなかったことは報告されない」という原則を導き、前工程の出力ではなく元の素材を独立に読み直す検査ステップで対応したと述べる。

事例・ノウハウ ★★★☆☆ rss:Qiita - ClaudeCode

Claude Code でモデルを切り替えると、そのターンだけ書き直しが287倍

Claude Code 2.1.251で可視化されたプロンプトキャッシュのトークン数を実測。同一モデルでセッションを継続する場合の書き直しは149〜197トークンなのに対し、Opus実行中にSonnetへ切り替えた瞬間だけ56,584トークン(287倍)が書き直しになった。原因は各モデルが独立したキャッシュを保持しており、切り替え時に蓄積済みのコンテキストキャッシュが失効するため。

💡 セッション途中のモデル切り替えが持つ具体的なコスト増を数値で示しており、AgAgが将来Issue経由の実行やサブエージェントでモデルを使い分ける設計を検討する際の実測データとして参照できる。
