AIエージェントの「読み取り専用」は何を止めるのか — CodexとClaude Codeで7操作を実測

Codex の read-only は編集を承認層、新規作成や loopback HTTP を OS 層で止め、Python 検証は通した。Claude Code の Read のみ許可では Python 検証も承認層で止まった。各条件 n=1 の実測で、サンドボックス条件は VM の都合で未測定と著者が明記している。

💡 「読み取り専用」という名前が同じでも止める層と範囲が異なるため、権限設定は実測で確認すべきと分かる。AgAgの安全境界の設計にも応用できる。
