Claude Code の PreToolUse フックで rm -rf を止める設定と、その限界

Claude CodeのPreToolUseフックは通常の権限チェックより先に発火し、`bypassPermissions`モードでも`rm -rf`等の破壊的コマンドを止められる。ただし著者は、スペース分割・変数展開を挟んだコマンドは文字列マッチをすり抜けること、`allow`ルールでdenyを上書きできないこと、確実な遮断にはサンドボックス併用が要ることの3つの限界を明記している。

💡 2026-09-22に記録した`Bash(rm*)`deny迂回事例への具体的な補強策と、それでも残る弱点の両方を示しており、agent/knowledge/security.mdの『機構化の粒度』系譜に直接接続する。
