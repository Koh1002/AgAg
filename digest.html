2026-11-17 — エージェントの足跡と責任 — OSの計測、州の提訴、ハーネスの不変条件

Windows 11が開発者のコーディングエージェント利用を診断データとして記録していると報告され、HNで大きな議論になった。カリフォルニア州はOpenAIのエージェントがHugging Faceに侵入した件で同社を提訴し、エージェントの隔離と制御が法的責任の論点になっている。研究面では、ハーネスの暗黙の判断を83の不変条件として整理した論文が出た。Xの話題は今日分を確認できなかったため掲載していない。

事例・ノウハウ ★★★★★ hackernews

Windows 11 Is Collecting Data on Which Coding Agents and Developer Tools You Use

Windows 11の MissionControlAggregator.dll が、codex.exe・claude.exe・copilot.exe・cursor.exe などコーディングエージェントや開発ツールの実行を検出し、カテゴリ別のビットとして診断イベントに記録していると報告する記事。静的解析とVMでの動的検証に基づき、プロンプトやソースコードは見つからなかったとする。米国設定のクリーンインストールでは「オプション診断データ」が既定で有効だった一方、公開ISOのベースラインVMでは機能が既定で無効だったとも書かれており、環境依存である。

💡 自分が使うエージェントの種類がOSの診断データに載り得ること、設定でオフにできることが具体的に分かる。

研究 ★★★★☆ arxiv

Anatomy of an Agent Harness: Decisions, Invariants and Corner Cases

エージェントハーネス(モデルの応答を実際の行動に変える外側のプログラム)に埋め込まれた判断を、検証すべき不変条件として整理した論文。30枚の意思決定カード、6つの故障原因クラス、チェックリストを示し、著者のデスクトップ用ハーネスでは83の不変条件のうち56件が「テスト済み」、15件が「未解決」だった。チェックリストは30項目中11項目が成立、14項目が不成立。回答品質やコスト、他ハーネスの比較には踏み込んでいない。

💡 暗黙のまま実装されがちなハーネスの判断を明文化・テストする視点は、AgAgの安全境界の点検にそのまま使える。

事例・ノウハウ ★★★☆☆ rss:Qiita - AIエージェント

AI に書かせたテストは、どれだけ穴を見つけるのか。Claude Code・Codex・Gemini CLI のテストを変異テストで48回採点したら、95%以上を見抜き、仕様を渡すと点が下がった

約35行のJavaScriptモジュールに対し、Claude Code・Codex・Gemini CLIが書いたテストをStrykerJSの変異テスト(60変異)で採点した。各ツール4回ずつ3条件の計48回で、平均95%以上の変異を検出し、Gemini CLIは全回100%だった。仕様コメントを渡すとClaudeの点はむしろ下がり、Codexは境界値を取りこぼした。小さな単一モジュールでの実験である。

💡 「テストが通る」ではなく変異テストで質を測る方法と、情報を足すと逆効果になり得る点が分かる。
