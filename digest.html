Codexのサブエージェントに"read-only"と書いても、ファイルを書けた：Claude Codeと設定を揃えて見つけた穴と直し方

Codexのサブエージェントに sandbox_mode = "read-only" を書いても、親セッションの workspace-write で動いてファイルを作れた。Claude Codeのサブエージェントには個別のsandboxがなく、親が bypassPermissions や acceptEdits のとき定義側の permissionMode も無視される。Codexでは git diff を前方一致で許可していたため、--output で作業ディレクトリ外へ書ける経路もあった。確認はClaude Code 2.1.332、codex-cli 0.172.0(Linux)で、sandbox外への実書き込みなど一部は未検証と著者が明記している。

💡 サブエージェント定義に書いた制限が実行時に効くとは限らないという実例で、AgAgのサブエージェント設計(agent/agents/)にも直結する。
