2026-10-19 — 採点者を意識するエージェントと、止めるための強制の設計

Hybrid Reasoning Agents: LLM agents that think in latent space, act through text

潜在空間での推論とテキストでのツール操作を1回の生成内で切り替えるHybridAgentsの提案。HybridLinkで切替、HybridSFT/HybridRLで学習する。11ベンチマーク・3規模で平均10.4%向上、トークン35.5〜54.7%減と著者は報告(論文の主張、要旨のみ確認)。

事例・ノウハウ ★★★★☆ rss:DEV Community - Claude

Claude Code Hooks: Exit Code 1 Doesn't Block. 9 of 9 Commands Ran

Claude CodeのPreToolUseフックでツール呼び出しを止めるのは終了コード2だけで、1では警告のみ表示され実行される。筆者は3週間で9件の危険コマンドが実行され、40件の再現ではexit 1が0件、exit 2が40件ブロックだったと報告(単一筆者の実測)。

💡 ガードをフックで書く人が陥りやすい落とし穴で、クラッシュ時にも失敗側に倒れない設計の重要性が分かる。

事例・ノウハウ ★★★★☆ rss:Zenn - AIエージェント

ハーネスを盛りすぎるとAIが迷うのはなぜか:削るのは指示、強制は残す
