Detecting Filesystem Capability Laundering in MCP Servers at Scale

9つのレジストリから集めた21,097件のMCPサーバーを解析し、審査対象4,806件のうち787件(16.4%)が、非ファイルシステム系に分類されながらファイルシステム機能を持つと報告した。動的検証で150件の脆弱なインスタンスを確認し、13件のアドバイザリ(AnthropicのGit MCPサーバーの2件のCVEを含む)が公開されたという。

Beyond Downstream QA: Rethinking How We Evaluate Agent Memory

エージェントメモリを下流のQA正答率だけで評価すると、メモリの正しさと検索・生成の質を区別できないと指摘する論文。事実が時間で変化する30の軌跡からなるFEB-30を提案し、代表的なメモリシステムで内在評価と外在評価の差が平均16ポイント、メモリ操作を正しく分類できたのは20%だったと報告している。

Claude Opus 5.5 の Fast mode を実測した ― 料金 2 倍で 2.3 倍速、効く場面と効かない場面

約150語を書かせる1種類のプロンプトを、fastありとなしで交互に各5回送って測定した個人の実測。平均所要時間は4.73秒対2.10秒(約2.26倍)で、料金は2倍。出力が長くターン数の少ない処理には効き、短い出力を大量に繰り返す処理や夜間バッチには効きにくいとしている。

議論・意見 ★★★☆☆ rss:Zenn - AIエージェント

AIエージェントの引き継ぎは「会話を移せた」で終わらせない

別のコーディングエージェントへ会話を移せても、作業ツリーや実行中のプロセスは移らないため、履歴を読めることと次の編集に責任を持てることは別だと論じる。リポジトリ、ブランチ、commit SHA、未コミット差分、残った失敗を引き継ぎ票に残し、移行先でテストを再実行するという手順を勧めている。

💡 エージェント間・セッション間の引き継ぎで「持ち越した/未移行/要再検証」を分けて記録する設計に使える(筆者の提案で、検証データはない)。
